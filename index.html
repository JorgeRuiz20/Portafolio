MotoStock — App Android

App Android nativa para la gestión completa de un taller de motos. Implementa tres roles de usuario con vistas y permisos diferenciados: CLIENTE, TRABAJADOR y ADMIN.

  • Sistema de roles con acceso diferenciado por pantalla y acción
  • Push notifications en tiempo real con Firebase Cloud Messaging (FCM)
  • Persistencia local offline con Room + sincronización a Firebase Firestore
  • Patrón MVVM con ViewModels, LiveData y StateFlow
  • Inyección de dependencias con Hilt (DI)
  • Consulta de datos de vehículo por placa vía Retrofit a API externa
  • Máquina de estados de citas: PENDIENTE → ACEPTADA / RECHAZADA → EN_PROCESO → FINALIZADO
  • Tests unitarios con JUnit + Mockito aplicando el patrón AAA (Arrange, Act, Assert)
  • Arquitectura por capas: presentation / domain / data / di

Robotech — Plataforma de Competencias y Torneo de Robótica

Sistema web full stack diseñado para organizar y arbitrar torneos de robótica en tiempo real, combinando control de acceso por roles (Juez, Competidor, Admin), generación dinámica de brackets de eliminatorias, evaluación técnica en vivo con puntuación por criterios, ranking instantáneo y módulo comercial de inventario y cotizaciones.

Qué construí

Un backend REST desacoplado para reglas de negocio, cómputo de puntajes y persistencia, junto a una SPA reactiva para competidores y jueces.

Cómo lo resolví

Spring Boot + JPA/Hibernate + MySQL en la nube (Render), seguridad granular por roles, y frontend dinámico con React + Vite + Axios y diseño responsivo.

JavaSpring BootJPA / HibernateMySQLReactViteAxiosReact RouterRender Cloud
  • Brackets interactivos y ranking en vivo
  • Panel de Juez con sistema de puntuación técnica
  • Panel de Competidor para registro y estado de robots
  • Gestión de inventario, kits de robótica y cotizaciones
  • Arquitectura REST segura y desplegada en la nube
  • Pruebas unitarias en backend con JUnit

Carwash H&R — Gestión Operativa & Fidelización

La operación de un lavadero concentra clientes, vehículos, servicios, caja e inventario. A partir de esa problemática construí una solución dividida entre un backend REST y una interfaz web para digitalizar el flujo comercial, arqueo diario y fidelización de usuarios mediante puntos.

Qué construí

Una API REST para la lógica de negocio y una SPA intuitiva para operar y consultar procesos desde una interfaz web moderna.

Cómo lo resolví

Spring Boot + MySQL para el backend, Docker para empaquetado y despliegue en Render, y React + Vite + Axios para la interacción frontend.

JavaSpring BootREST APIMySQLDockerReactViteAxiosRender
  • Gestión integral de servicios, clientes y empleados
  • Caja diaria, registro de pagos y arqueo
  • Sistema de fidelización por acumulación de puntos
  • Inventario y control de insumos en tiempo real
  • Frontend responsive conectado a la API REST
  • Despliegue containerizado en la nube
💡 Demo disponible: Las credenciales de prueba están indicadas directamente en la pantalla de inicio de sesión de la aplicación.

MotoStock — App Android Nativa para Taller

Un taller de motos necesita controlar repuestos, servicios, vehículos y citas sin depender de procesos dispersos. La propuesta fue llevar esa operación a una aplicación Android centralizada, con persistencia local offline-first, acceso por roles y sincronización en la nube.

Qué construí

Una app nativa para gestionar inventario, historial de servicios por placa y agenda de citas, con autenticación y persistencia.

Cómo lo resolví

Clean Architecture, Jetpack Compose, ViewModels/StateFlow, Room para persistencia local, Firestore para sincronización y Hilt para inyección de dependencias.

KotlinJetpack ComposeClean ArchitectureMVVM / StateFlowHiltRoom DBRetrofitFirebase
  • Roles CLIENTE / TRABAJADOR / ADMIN
  • Firebase Auth + Google Sign-In
  • FCM para notificaciones push automáticas
  • Room + Firestore para persistencia local y sincronización
  • Consulta de datos de vehículo vía API REST externa
  • Tests con JUnit + Mockito y patrón AAA
📱 Aplicación Móvil: Desarrollada en Kotlin nativo con Jetpack Compose y arquitectura Offline-First.

RinRed — Reservas de Taxi en Cusco

Experiencia digital sencilla para cotizar y solicitar un taxi, consultar viajes en curso o finalizados y gestionar cancelaciones para transporte dentro de Cusco. El proyecto implementa un flujo completo entre una interfaz web interactiva y una API REST robusta.

Qué construí

Un frontend multipágina para explorar el servicio, solicitar taxis en tiempo real, consultar viajes y revisar detalles del conductor.

Cómo lo resolví

Backend con Spring Boot 3.5.3, Java 21, Spring Data JPA y MySQL en Render; frontend con HTML, CSS, JavaScript y Bootstrap.

Java 21Spring Boot 3Spring Data JPAMySQLDockerHTMLCSSJavaScriptBootstrapRender
  • Solicitud de taxi en tiempo real
  • Consulta de viajes pendientes y finalizados
  • Cancelación y seguimiento de estado de viajes
  • Consulta de información y asignación del conductor
  • Integración frontend ↔ API REST en la nube
  • Interfaz responsive optimizada para web y móvil
